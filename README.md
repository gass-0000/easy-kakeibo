# かんたん かけいぼ

GitHub Pagesでそのまま使える完成版です。データは端末のブラウザ内だけに保存されます。

## 公開手順

1. ZIPを展開します。
2. GitHubのリポジトリを開きます。
3. **Add file → Upload files** を選びます。
4. ZIP内のファイルをすべてアップロードします。
5. **Commit changes** を押します。

初回だけ **Settings → Pages → Deploy from a branch → main → /(root)** を選択してください。設定済みの場合は、以後ファイルをアップロードしてCommitするだけで更新されます。
